Đổi được

Ảnh (JPG, PNG, WEBP, HEIC iPhone, AVIF, TIFF, BMP, GIF) →

JPGPNGWEBPPDFScanDOCXTIFF

PDF → JPG · PNG · WEBP (mỗi trang 1 ảnh), TXT · DOCX (lấy chữ)
Word, TXT → PDF · TXT · DOCX · ảnh
Excel (XLSX, XLS, CSV) → PDF · PNG · JPG · CSV · XLSX

Gộp / Tách

Kéo nhiều file (ảnh, PDF, Excel lẫn lộn) vào ô Gộp PDF → 1 file PDF.
Nhiều file Excel → ô Gộp Excel → 1 file, mỗi file 1 sheet.
Kéo 1 PDF nhiều trang → Tách trang; 1 Excel nhiều sheet → Tách sheet.

Mẹo

  1. Kéo nhiều ảnh, PDF vào ô Gộp PDF là gộp thành 1 file, theo thứ tự anh chọn.
  2. Kéo file trong "File vừa làm" thả lại vào trang để làm tiếp (vd: Cắt xong rồi Thêm nền).
  3. Nhanh nhất: Ctrl + T mở Tab mới rồi kéo file vào.
